# 薪資管理系統 (Xinle Salary System)

## 專案簡介
為企業內部設計的自動化薪資管理系統。系統提供員工資料管理、出勤時數紀錄以及薪資自動試算功能，並透過關聯式資料庫確保財務數據的完整性與安全性。

## 技術
* **後端框架**: Python, Flask
* **資料庫**: MySQL
* **版本控制**: Git

## 功能
* **員工管理模組**: 支援 CRUD（新增、讀取、更新、刪除）員工基本資料與職級。
* **薪資計算引擎**: 根據出勤紀錄、底薪與津貼，自動試算當月應發薪資。
* **資料庫串接**: 透過 Python 安全地連接 MySQL，執行複雜的關聯查詢與資料正規化處理。
